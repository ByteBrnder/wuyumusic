# 雾屿音乐

> 把喜欢的歌，带来这里。

雾屿音乐是一款以本地音乐为核心的播放器，采用白色亚克力界面，将专辑封面、同步歌词与随音乐起伏的三维粒子融入聆听体验。

项目使用 **uni-app + Vue 3** 构建，主要面向 **Android 和 Web**。歌曲保存在本机，可自行导入、整理和备份。

## 主要功能

### 本地音乐库

- 支持多首音频导入、内容指纹去重、取消导入及失败重试。
- 音频保存后即可播放，后台补全歌曲标签、内嵌封面和歌词。
- 按歌手、专辑和歌单整理，支持搜索、收藏、多选管理及歌单排序。
- 可编辑歌曲信息、手动更换封面，或为失效歌曲重新关联音频文件。
- 移除歌曲时清理应用保存的副本，保留设备中的原始文件。

### 播放与歌词

- 上一首、下一首、进度拖动，以及列表循环、单曲循环和随机播放。
- 播放队列支持调整顺序、指定下一首和移出歌曲。
- 支持内嵌歌词、本地 LRC 文件与联网查找同步歌词。
- 歌词版本可预览后选择，支持点击跳转、手动浏览、恢复跟随与时间校准。
- 保存播放进度、队列与模式；提供定时停止及本曲结束停止。

### 粒子音乐空间

- 从专辑封面采样颜色，让颗粒随音乐音量与低频变化呼吸、流动。
- 在封面、几何形态、世界建筑及风景图案之间随机变换。
- 支持拖动旋转、双指缩放、聚合封面和隐藏控件的沉浸模式。
- 自定义最多 8 句粒子文字，每句最多 12 个字，提供字体与排版预览。
- 画质、呼吸强度、变化间隔、图案收藏及缓存集中在“视觉设置”中。
- 根据运行负载调整粒子数量，并适配系统减少动画、省电及温控状态。

### 系统集成与数据备份

- Android 接入后台音频管理器、MediaSession 和系统媒体通知。
- 提供系统粒子动态壁纸入口，支持同步封面颜色、音乐律动与文字设置。
- Web 接入浏览器 Media Session，可使用支持此能力的系统播放控件。
- 完整备份包含音频、封面、歌词、收藏、歌单和相关设置；恢复时合并音乐库并去重。

## 快速开始

安装 Node.js 18 或更高版本，然后执行：

```bash
git clone https://github.com/ByteBrnder/wuyumusic.git
cd wuyumusic
npm ci
npm run dev:h5 -- --host 127.0.0.1 --port 5175
```

在浏览器中打开 `http://127.0.0.1:5175/`，即可导入本地歌曲。

打开 `http://127.0.0.1:5175/?demo=1` 可体验项目内置的演示音频、封面和模拟歌词。

## 构建与运行

| 命令 | 用途 |
| --- | --- |
| `npm run dev:h5` | 启动网页开发服务，包含歌词代理 |
| `npm run build:h5` | 构建 Web 资源，输出到 `dist/build/h5` |
| `npm run start:h5` | 启动构建后的网页与歌词代理服务 |
| `npm run build:app` | 构建 App 资源，输出到 `dist/build/app` |
| `npm test` | 运行核心逻辑与工作流程测试 |

### Android 打包

使用支持 UTS 原生插件的 HBuilderX 打开项目，配置应用标识及 Android 打包信息，再制作自定义基座或完整 APK。

`npm run build:app` 生成的是 App 资源，**不是可直接安装的 APK**。修改原生 Kotlin、UTS 接口或服务清单后，需要重新打包，单独更新网页资源无法完成原生模块更新。

系统媒体卡片、顶部播放胶囊、后台存活与动态壁纸的应用范围，由系统版本、权限和厂商策略共同决定，部分场景仍需真机验证。动态壁纸通过系统预览页确认应用；完全息屏时停止绘制。

### Web 部署

```bash
npm run build:h5
npm run start:h5
```

默认访问 `http://127.0.0.1:4175/`，可通过 `PORT` 环境变量调整端口。服务默认监听本机地址；对外部署时需要配置反向代理。

Web 联网歌词使用同源代理，发布时需同时运行代理服务。仅部署静态文件时，本地播放仍可使用，联网歌词需要另行配置代理。

## 本地存储与联网说明

- Android 将导入的音频副本保存在应用私有目录；Web 使用 IndexedDB 保存音频和封面。
- Web 音乐库与浏览器、站点地址绑定，清理站点数据或更换浏览器后，需要从备份恢复。
- 联网歌词仅发送歌名、歌手等查询信息，不上传音频；可在音乐库管理中关闭自动获取。
- 歌词匹配依赖第三方服务，覆盖范围、网络和接口调整可能影响结果；可随时改用本地 LRC。
- 音乐律动在本机分析，不使用麦克风。大文件或不支持的解码格式会降级为舒缓流动。
- 音频格式能否播放取决于浏览器或系统解码能力；封面与歌词能否自动提取取决于文件是否包含可识别的标签。
- 完整备份包含音频，文件可能较大；恢复大型 JSON 备份时仍受设备内存限制。

## 项目结构

```text
src/
├── pages/index/           # 音乐库、播放页与操作面板
├── components/           # 粒子封面、歌词、列表和应用内展示
├── utils/                # 播放、导入、存储、歌词、粒子与备份
├── uni_modules/
│   └── wuyu-media-session/ # Android 系统媒体会话与粒子壁纸
└── static/               # 图标与演示资源
server/                   # Web 歌词代理和静态资源服务
tests/                    # 核心逻辑与工作流程测试
design/                   # 图标设计资源
```
