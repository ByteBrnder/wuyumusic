# 雾屿音乐

白色亚克力风格的本地音乐播放器，使用 uni-app / Vue 3，面向 Android 与 H5。

## 使用

```powershell
npm run dev:h5 -- --host 127.0.0.1 --port 5175
```

访问 `http://127.0.0.1:5175/?demo=1` 可加载两首演示纯音乐、封面和模拟歌词。普通入口不自动添加演示歌曲。

## 本次功能

- 多文件导入、音频内容指纹去重、内嵌封面与歌词提取、逐文件失败提示。
- H5 使用 IndexedDB 保存音频和封面；Android 导入到应用私有目录。
- 恢复上次歌曲、进度、队列和播放模式，重新打开时保持暂停。
- 固定播放控制区、独立封面和歌词视图、上一首/下一首、进度拖动。
- 歌词点击定位、手动浏览、回到当前歌词、提前/延后校准。
- 网易云国内源同步歌词：导入或首次播放时尝试补全，支持修改查询、选择版本、保存后离线显示。旧版保存的 LRCLIB 歌词继续离线可用。
- 队列排序、下一首播放、移出队列；列表循环、单曲循环和随机播放。
- 喜欢、歌单、歌手/专辑分类、搜索、编辑歌曲信息、替换封面和歌词。
- 定时停止与本曲结束停止。
- 完整 JSON 备份包含音频、封面、歌词、喜欢状态和歌单；恢复按音频内容去重，同名歌单合并。
- Android 背景音频管理器与媒体通知按钮；H5 使用浏览器 Media Session。
- 查看其他歌曲使用独立详情面板，原歌曲继续播放；封面编辑与歌词导入集中在右上角歌曲菜单。
- 长歌词完整换行，按实际行高居中跟随；手动浏览后可回到当前句，支持减少动态效果的系统偏好。
- 缺少标签时按常见文件名格式推测信息并标记待核对，编辑页可重新填入、交换歌名/歌手后确认保存。
- 超过 100 首的歌曲列表采用固定行高虚拟渲染，队列每次展示 60 首；载入音乐库按 40 首分批处理。
- 备份逐首序列化：H5 分段构建 Blob，Android 直接写入文件流；显示导出和恢复进度。
- Android 耳机/蓝牙音频断开时暂停；系统暂停后显示恢复提示，保持暂停直到用户主动继续。

## 编译

```powershell
npm run build:h5
npm run build:app
```

输出分别为 `dist/build/h5` 和 `dist/build/app`。App 编译产物不是 APK；通过 HBuilderX 配置应用标识并打包安装。

## 国内歌词源与网页部署

- Android 使用 HTTPS 直接访问 `music.163.com`，仅在网络或服务端故障时尝试 `interface3.music.163.com`；不使用海外歌词源。
- H5 因上游缺少跨域许可，使用同源 `/api/lyrics/netease/search` 和 `/api/lyrics/netease/lyric`。开发模式已在 Vite 中接入代理，无需额外配置。
- 网页发布使用 Node.js 18+，先执行 `npm run build:h5`，再执行 `npm run start:h5`，默认入口为 `http://127.0.0.1:4175/`，可通过 `PORT` 环境变量调整端口。该服务同时提供网页和歌词代理；仅上传静态文件不能使用国内歌词搜索。
- 代理只允许固定的搜索/歌词路径，校验歌名与歌曲编号，不转发用户 Cookie 或提供任意地址转发。上游限流时保留冷却提示，不切换地址绕过限制。
- 此接口当前网络实测可用，但不是有可用性承诺的开放平台接口，上游调整、风控和地域网络仍可能导致失败。

## 当前验证范围与限制

- H5 和 App 资源编译已通过；网页预览可显示封面、歌词与播放控件，刷新后恢复进度并暂停。
- Android 通知、锁屏操作、后台连续播放及后台定时精度尚未经过 APK 真机验证；实际行为受系统版本、通知权限与系统省电策略影响。
- 不支持应用被系统终止后继续播放。Android 通知控制不等于完整的原生 MediaSession/耳机按键集成。
- H5 数据属于当前浏览器和站点地址；换端口、换浏览器或清理站点数据不会自动迁移音乐。旧版仅有临时 blob 地址的歌曲需重新导入。
- JSON 音频编码体积约为原始二进制的 4/3。导出避免将整个音乐库同时构建为大字符串；单首音频仍需编码，恢复仍需读取并解析完整 JSON，因此超大备份仍有内存限制。
- 未写入封面的音频可手动导入图片。同步歌词通过国内网易云源搜索，只发送歌曲信息，不上传音频。自动获取可在音乐库管理中关闭。
- 自动歌词匹配要求歌名、歌手一致且时长相差不超过 2 秒；缺少歌手、未能读取时长或只有不确定版本时，使用“联网找歌词”手动选择。已有同步歌词不会被自动覆盖；手动替换需确认。
- 接口有覆盖范围、网络及限流限制，失败不会影响播放或本地歌词。查询串行，每个上游请求超时受限，只为最多 6 个候选获取歌词，同时最多 2 个歌词请求；失败后至少冷却 60 秒，同一信息自动尝试最多 3 次，限流时遵守服务冷却时间。支持手动重试、网络恢复后重试及更正信息后重新匹配。结果缓存 5 分钟，保存的歌词随音乐库与完整备份保留。
- 兼容旧 WebView：歌曲名归一化不使用 Unicode 属性正则，缺少 `String.normalize` 时可降级；歌词时间戳解析不依赖 `String.matchAll`。
- 音频焦点与来电中断依赖 uni-app 背景音频管理器；本次增加了暂停状态同步与耳机断开处理，没有实现独立原生播放服务或完整耳机按键接管。当前环境未发现 adb/HBuilderX 命令，未进行安卓真机中断/锁屏检查。

## 本轮验证记录

- 单元测试覆盖歌词解析/定位、版本匹配、失败冷却与重试上限、文件名推测、虚拟窗口和备份校验。
- 网页检查：播放歌曲时查看另一首详情不切歌、不暂停；歌词停止滚动后当前句中心与视区中心差为 0 像素；手动浏览后可返回。
- 隔离站点导入 130 首本地生成短音频：首屏只渲染 12 行，列表末尾渲染 14 行，保留完整 9360 像素滚动高度。
- 该检查库完整导出后，JSON 可解析，130 首音频的 SHA-256 与记录全部一致；检查库使用 localhost 站点，与日常 127.0.0.1 音乐库隔离。

## 主要代码

### 使用体验优化

- 粒子主画面保留变换图案、聚合封面、沉浸，独立的“视觉设置”入口提供省电/均衡/精细三档、自动变化开关、6–30 秒间隔、图案收藏与仅收藏播放、静态封面及视角归位。设置和收藏保存在本地。
- 三档粒子预算约为 1100/2200/3364，绘制帧率上限为 24/30/45；持续绘制耗时偏高时逐步减少数量。实际帧率取决于设备刷新率与负载。双指缩放范围 0.6–2.2 倍，电脑滚轮也可缩放；拖动松手后有衰减惯性。减少动态效果模式不启用惯性。
- 视觉设置显示本地分析缓存占用，清理仅移除粒子分析缓存，不删除歌曲、封面文件、歌词或歌单；当前画面的工作数据保留，之后可重新生成缓存。
- 导入显示当前文件阶段、单首和总体处理进度、本批耗时及当前文件耗时。安卓复制按字节更新，其他阶段按处理节点更新。支持取消；浏览器哈希/存储操作无法中途打断，会在操作结束后的检查点取消。已提交歌曲保留，未提交的应用副本清理。空文件拒绝导入。
- 本次会话保存未成功文件的引用，可仅重试失败/取消项目；如果文件授权已失效，需重新选择。不会重试已成功导入的歌曲。
- 歌曲菜单与详情页提供内嵌信息补全，仅补缺失封面和歌词；现有手动封面/歌词保留。无内嵌内容时给出提示，歌曲原文件不修改。
- 回到前台同步音频实际暂停状态、时间与歌词，不主动恢复被系统暂停的播放；应用后台停止粒子绘制。网页系统控件支持停止、前后跳转，安卓通知权限从系统设置返回后重新检查。
- 当前环境没有 adb，未连接安卓设备；锁屏、来电、耳机和后台存活检查仍未完成，见 `ANDROID_PLAYBACK_CHECKLIST.md`。

### 颗粒封面与导入优化

- 安卓导入在同一遍文件复制中计算 SHA-256，缓冲区由 64 KiB 增至 512 KiB，减少完整读取次数与 NativeJS 调用。自动歌词匹配在本批导入结束后启动；尚未测量真机提速比例。
- 封面页默认开启颗粒效果，按原图采样颜色；可切换静态封面。绘制在 renderjs 视图层执行，上限 30 帧/秒、像素比上限 1.5，暂停、切到歌词页、页面不可见或系统减少动态效果时停止连续绘制。
- 使用本地音频解码后的 RMS 音量包络驱动颗粒，不使用麦克风、不额外播放音频。拖动进度后按新时间同步。分析按需执行，不占用导入流程；最近三首包络缓存在内存中。
- 为控制内存，超过 50 MiB 的歌曲使用舒缓流动；解码不支持或失败时显示降级提示。安卓在开启效果时需要将当前音频读取到视图层，真机解码兼容性与性能仍待确认。
- 粒子画布覆盖底部播放器上方的整片区域，歌曲信息和顶部按钮浮于其上。播放时在球体、星环、双螺旋、曲面之间随机变形，封面也参与随机变化；透视投影、深度排序和明暗表现立体感。
- 中心区域上下左右拖动旋转，右边缘左滑切歌词，也可点顶部歌词按钮。支持暂停时旋转、手动聚合封面和视角归位；键盘方向键旋转、Home 归位。底部播放器不参与粒子手势。
- 建筑图案包括埃菲尔铁塔、吉萨金字塔、悉尼歌剧院、北京天坛和上海东方明珠的简化三维意象，统一加入“变换图案”，与自动变化共用洗牌队列；几何图案、建筑、雾屿音乐文字及封面均参与，每轮打乱顺序、避免连续重复，不再固定间隔返回封面。建筑保留封面采样颜色，支持旋转与音乐律动。
- 粒子文字默认保留“雾屿音乐”。播放页“视觉设置 → 自定义粒子文字”支持最多 8 句、每句 12 个字，提供黑体 / 宋体 / 等宽、单行 / 分行排版及即时预览。设置持久化并参与随机变化，也可清除；应用内展示及安卓系统壁纸均接收文字设置。
- 收起播放器仅隐藏视图，保留画布、形态和视角，并停止绘制；再次打开无需重新采样。封面像素采样与音量包络按稳定文件标识写入本地缓存，各保留最近三份，总序列化体积限制约 1.5 MB；重启后可复用。缓存配额不足、不可用或数据无效时重新分析，不影响播放。缓存不包含原始音频。

### 系统播放胶囊与锁屏展示

播放页“视觉设置”可进入带时钟的应用内锁屏展示。系统“流体云”指应用退到后台后的顶部播放胶囊及展开音乐卡片。已新增 Android MediaSession 原生模块作为接入基础，目标 OPPO Find X8 / ColorOS 16.0.7；胶囊实际展示待真机确认。新增服务后必须重新打包自定义基座 / APK。常亮需手动开启；退出或退到后台释放。Android 已新增系统粒子动态壁纸服务，入口为播放页“视觉设置 → 设为锁屏粒子壁纸”，需重新打包并经系统预览确认。Find X8 的实际应用范围尚待真机验证，详见 [LOCKSCREEN_INTEGRATION.md](LOCKSCREEN_INTEGRATION.md)。


### 本轮稳定性与日常使用优化

- 导入先保存音频并提交到音乐库，封面、标签、歌词在串行队列中补全；补全状态持久化，重启可续处理。补全失败保留可播放文件并在详情提供重试，不覆盖用户处理中手动编辑的信息。
- 音乐库支持多选收藏、加入已有 / 新建歌单和批量移除；歌单支持改名和歌曲上移 / 下移。移除清理应用管理的副本，保留用户手机中的原始音乐文件。
- 歌曲详情及操作菜单提供重新关联音频，保留歌曲标识、歌单关系、收藏、封面和歌词；不同指纹文件需要确认替换。
- 歌词候选先预览前 8 行时间戳再使用；时间偏移可重置。手动触摸停止自动滚动，回到当前歌词后重新跟随。
- 备份包含视觉设置、自动歌词开关和循环模式；恢复可选择是否应用备份设置，继续兼容旧版备份。歌曲提交后的设置失败不回滚删除音频。
- 安卓诊断展示通知、媒体会话、省电模式、电池优化和温度等级，提供系统设置入口及复制诊断。H5 明确提示安卓功能需安装包。
- 应用粒子按实际绘制耗时及帧间隔降级，持续流畅后缓慢恢复。安卓省电 / 中度温控降低负载，严重温控暂停自动流动；壁纸监听温度恢复，息屏停绘。
- 新增 `tests/music-workflows.test.mjs`，覆盖分阶段导入、去重、取消、补全失败、编辑竞争、重新关联、批量管理、恢复事务和设置迁移。
- 原生变更需要重新制作自定义基座或完整 APK。OPPO Find X8 / ColorOS 16.0.7 尚未连接，胶囊、来电、耳机恢复、系统壁纸与耗电表现仍待真机检查。
